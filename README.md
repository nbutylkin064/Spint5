# Sprint_5 - Автотесты для Stellar Burgers

Проект содержит автоматизированные тесты для сервиса Stellar Burgers.

## Структура проекта.

test_registration.py - файл с проверками регистрации
test_login.py - файл проверки четырех сценарий авторизации в приложении
test_profile.py - файл с проверками перехода по клику:
на «Личный кабинет» в личный кабинет
на «Конструктор» из личного кабинета в конструктор
на логотип Stellar Burgers из личного кабинета в конструктор
по кнопке «Выйти» из личного кабинета
test_constructor.py - файл проверки переходов к разделам в разделе «Конструктор»
conftest.py - файл с фикстурами
locators.py - файл с локаторами элементов используемые в тестах
data.py - файл с адресом сайта Stellar Burgers и валидными значениями аккаунта

## Команды.
Основа для написания автотестов — фреймворк pytest и инструмент Selenium WebDriver.
Установить зависимости — pip install -r requirements.txt
Установить pytest — pip install pytest
Установить Selenium WebDriver — pip install selenium
Команда для запуска — pytest -v
